## المشكلة

سير العمل الحالي يمرّ بإنسان في المنتصف:

```text
PDF → ChatGPT/Claude/Kimi → Markdown → واشي
```

وهذا **قرار صحيح** لنسخة 0.5 (الاستخراج ليس دور واشي). لكن ما ينقص هو
**استيراد Markdown من الدرجة الأولى** في كل الواجهات.

### الفجوة الحالية

| الواجهة | الاستيراد |
|---------|-----------|
| CLI | ✅ `--file` + stdin (`cli/commands/new.ts:18,25`) |
| MCP | ✅ `washi_new` يستقبل النص |
| **Studio** | ❌ **textarea + رابط sample فقط** — لا file picker، لا drag&drop |

- `app/projects/page.tsx` — `textarea` + `SAMPLE_URL`
- `app/page.tsx` — محرر Markdown، بلا استيراد ملف
