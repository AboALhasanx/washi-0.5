# خطط واشي (Washi Plans)

هذا المجلد هو **مصدر الحقيقة الوحيد** للخطة والتودوهات. الغرض: ألّا تضيع الخطة داخل سياق
الجلسة (context) عند تبديل الوكلاء أو المحادثات.

**مُودَع في Git وليس في `.gitignore`** — أي تغيير يُلتزم به.

---

## البنية

```text
plans/
├── README.md          ← هذا الملف: كيف تستخدم المجلد
├── master-plan.md     ← التقييم الكامل + الخطة الأساسية (M0–M7)
├── TODO.md            ← قائمة المهام القابلة للتحقق ✅ (ابدأ من هنا كل جلسة)
└── phases/
    ├── phase-0-test-harness.md
    ├── phase-1-publication-integrity.md
    ├── phase-2-contracts.md
    ├── phase-3-boundaries.md
    ├── phase-4-lifecycle.md
    ├── phase-5-production-validation.md
    ├── phase-6-ingestion-docs.md
    └── phase-7-editor-ux.md      ← مؤجل
```

## كيف تستعمله

1. **ابدأ كل جلسة بقراءة `TODO.md`** — يعرض المرحلة الجارية والمهمة التالية.
2. نفّذ المهمة، ثم **حدّث `TODO.md`**: حوّل `[ ]` إلى `[x]`، وأضف تاريخ الإنجاز.
3. إن اكتشفت مهمة جديدة أثناء التنفيذ، أضفها إلى ملف المرحلة المقابلة وإلى `TODO.md`.
4. المرحلة تكتمل فقط عند تحقيق **كل معايير القبول** في ملفها.

## حالات المهمة

| الرمز | المعنى |
|-------|--------|
| `[ ]` | لم تبدأ |
| `[~]` | جارية |
| `[x]` | مكتملة (مع التاريخ) |
| `[-]` | مُلغاة / مُؤجَّلة (مع السبب) |

## قواعد صارمة

- **لا تُلمس حزمة منشورة.** الحزم المجمّدة (`publications/vN/`) للقراءة فقط.
- **لا تُضف ميزات جديدة** قبل إكمال M0–M2.
- ممنوع حاليًا: AI داخل واشي، استخراج PDF، SaaS، قاعدة بيانات، Marketplace،
  محرك اختبارات طلابي، نظام طلاب، تحليلات تعلم.
