# Washi 0.5

Washi 0.5 is the first focused milestone of Washi: an Educational Content Publisher.

Its job is to turn structured educational Markdown into a professional, editable, rebuildable publication package for the educational platform.

This repository is intentionally documentation-first. It records the product and architecture decisions reached for Washi 0.5 before implementation begins.

## Codex starting point

Read [`WASHI_0.5_CODEX_BOOTSTRAP.md`](WASHI_0.5_CODEX_BOOTSTRAP.md) completely before making implementation decisions. Treat it as the current product brief and initial engineering context.

## Upstream reference

The original Washi repository is [AboALhasanx/washi](https://github.com/AboALhasanx/washi).

## Milestone test

Washi 0.5 is successful when one real competitive-exam chapter can pass through:

`External AI → Markdown → Washi → Human edit → Preview → PDF → Publish → Educational Platform`

The result must be beautiful, fast enough for production work, editable, reproducible, stable, traceable, and usable by the platform.
